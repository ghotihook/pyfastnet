# Golden baseline (v2 → v3 regression anchor)

`v2_baseline.json` is a deterministic snapshot of the **current (v2) complete-decode**
of every capture in `temp/`, generated by `generate_baseline.py`. It exists to protect
the v3 rewrite (see `../../docs`… i.e. pyfastnet `docs/v3_signalk_mapping.md`).

## What's in it
- **`files[*].decode_sha256`** — hash of the full ordered frame decode per capture.
  Any change to the decoder's `value` / `display_text` / `layout` output flips the hash.
  The v3 decoder stays *complete* (only the public output shape changes), so these
  internal decode values must not drift.
- **`channels[*].distinct`** — every distinct `(value, display_text, layout)` a channel
  produced, with counts. This is the **reference the v3 `{signalk_path: SI_value}`
  projection must derive from** (e.g. a v2 `Boatspeed (Knots)` of `6.2` must project to
  `navigation.speedThroughWater = 6.2 × 0.514444`).

## Regenerate
```
python tests/golden/generate_baseline.py
```
Deterministic — re-running on unchanged code produces a byte-identical file.

## Guard test
`tests/test_golden.py` recomputes each capture's decode hash and asserts it matches
this file. It guards the decoder through the pre-v3 fixes. **At the v3 cut-over** (when
the public decode output becomes `{path: value}`), update the guard to hash the retained
complete-decode path, and add a separate projection test that checks paths/units/values
against `channels.distinct`.
