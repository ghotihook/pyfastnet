# Golden baseline — complete-decode regression anchor

`v2_baseline.json` is a deterministic snapshot of the **complete decode** of every capture
in `temp/`, generated by `generate_baseline.py`. It is the decoder's long-running
regression anchor: the file was first generated at 2.0.18 and still matches today, so the
internal decode has provably not drifted across the whole v3 rewrite and the 3.2.0 schema
migration.

The name says `v2` for historical reasons — it was created to protect the v3 rewrite. It
guards the same thing now as it did then, so it has been left alone rather than renamed and
regenerated, which would throw away exactly the continuity that makes it valuable.

## What's in it

- **`files[*].decode_sha256`** — hash of the full ordered frame decode per capture. Any
  change to the decoder's `value` / `display_text` / `layout` output flips the hash.
- **`channels[*].distinct`** — every distinct `(value, display_text, layout)` a channel
  produced, with counts.

The complete decode is still reachable in current versions via `FrameBuffer(project=False)`
— the default `{signalk_path: SI_value}` projection is derived from it, not a replacement
for it. That is what lets this baseline keep working: `generate_baseline.py` hashes the
complete decode, so it is unaffected by changes to the projection layer.

## Regenerate

```
python tests/golden/generate_baseline.py
```

Deterministic — re-running on unchanged code produces a byte-identical file, apart from the
`meta.pyfastnet_version` string. **Only regenerate when a decode change is intended**, and
say why in the commit; a silently regenerated baseline is a guard that no longer guards.

## Guard test

`tests/test_golden.py` recomputes each capture's decode hash and asserts it matches this
file, one parametrised test per capture (8 in total). It complements the two other layers:

| Layer | Catches |
|---|---|
| `tests/test_golden.py` (this) | Any drift in the complete decode, across every captured frame |
| `tests/test_*.py` (per-channel) | Wrong values for the 41 channels with real-frame evidence |
| `tests/test_schema_valid.py` | A malformed `fastnet.json` — structure, not protocol facts |
